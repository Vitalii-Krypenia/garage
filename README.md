# Облік клієнтів СТО

Локальна браузерна програма для ведення клієнтів, авто та ремонтів на СТО.

## Як запустити

1. Відкрийте файл `index.html` у браузері.
2. У вкладці **Клієнти** додайте клієнта.
3. Додайте авто клієнта.
4. У вкладці **Планування** записуйте авто на майбутні роботи.
5. У вкладці **Довідник робіт** заповніть типові роботи і ціни.
6. Додавайте виконані роботи, запчастини, серійні номери, ціни та пробіг.

Дані зберігаються локально у браузері на цьому комп'ютері.

## Резервна копія

Кнопка **Експорт бази** зберігає файл `.json` з усіма клієнтами, авто та ремонтами.

Кнопка **Імпорт бази** відновлює базу з такого файлу. Імпорт замінює поточні локальні дані.

## Що вже є

- Клієнти: ім'я, мобільний, нотатки.
- Працівники: список майстрів для планування робіт.
- Планування: календар завантаження, записи на дату, вибір клієнта, авто та працівника, вихідні дні.
- Локальний вхід: адміністратор бачить усі розділи, працівник бачить свої заплановані роботи.
- Авто: VIN, держ. номер, марка/модель, рік авто, пальне, КПП, об'єм мастила, одометр, фільтри.
- Довідник робіт: найменування типової роботи, ціна та тривалість виконання.
- Ремонти: дата, пробіг після роботи, чеклист типових робіт, опис, ціна роботи.
- Діагностика ходової: комбінований чеклист плюс поле для додаткових висновків.
- Запчастини: назва, серійний номер у базі, кількість, ціна за штуку, сума.
- Друк акта виконаних робіт для клієнта з роботами, запчастинами, цінами та підсумком.
- Автоматичний підрахунок залишку кілометрів до заміни мастила.
- Пошук по клієнтах, телефонах, авто та номерах.
- Обідня перерва у плануванні за замовчуванням: 13:00-14:00.
- Зайнятість у календарі рахується з урахуванням кількості працівників.
